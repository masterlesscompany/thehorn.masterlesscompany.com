## 발견 — 합본 (같은 것은 합치고 심각도는 높은 쪽)

### P0

**P0-1. 재계획 트리거 4종 중 "이탈"·"적응 감지"가 러너에서 절대 발동하지 않는다** (심사위원)
`core/runner.py` 의 `replan.new_turn()` 이 턴 시작에 `deviations`·`adaptations` 를 비우는데, 그 두 리스트는 **직전 턴 안에서** 채워진다. 계측: 160판에서 `replan_trigger.trigger` 분포가 `{odds_collapse: 43}` 뿐인데 같은 판들에 deviate 1509회·boss_adapt 403회. 기획서 §8.3 의 트리거 4종 중 2종이 죽어 있고, `forced` 경로(설계 §6.3)도 도달 불가.

**P0-2. 결정론 테스트가 항상 빨갛다 — `latency_ms` 가 payload 에 들어간다** (심사위원·코어)
`adapters/harness/harness.py` 의 `time.perf_counter()` 가 `decision.payload.model.latency_ms` 로 실린다. `tests/test_runner.py::test_같은_시드는_같은_트레이스를_만든다` 가 13회 연속 실패. `test_store_replay.py` 는 `model` 키를 통째로 빼서 통과 — 두 테스트가 결정론을 다르게 정의한다.

**P0-3. 같은 시드가 프로세스마다 다른 판을 만든다 — set 순회** (코어·심사위원)
`core/agents/boss.py` 의 `for actor in {h.actor for h in recent}` 가 `PYTHONHASHSEED` 에 따라 순서가 바뀐다. 160판 중 6판이 해시시드에 따라 다른 트레이스(승패까지 갈림). 리플레이·E1 워커가 다른 프로세스면 전제가 깨진다.

**P0-4. 전사는 공격하지 않는다 — 가렛은 40판 동안 총 피해 0** (트롤픽)
`adapters/llm/fake.py` `_act()` 가 스태미나 ≥50% 이면 스킬 목록 첫 번째를 고르는데, 전사 스킬 순서가 `("방패 밀치기", "강타")` 이고 방패 밀치기는 `target=None` 인 self-guard 다. 기본 파티 시드 1..20 결과가 `draw 15/20`. E1 "전사 몰빵" 실험이 무의미해진다.

**P0-5. 1판에서 죽은 캐릭터가 2판에 만피로 부활한다** (트롤픽)
`core/runner.py` 의 `run()` 이 `members` 를 매 미션 그대로 넘기고 `res.dead` 를 반영하지 않는다. 기획서 §6.6 "사망 = 소멸".

### P1

**P1-1. 감독의 후퇴가 규칙이 아니라 Fake 모델의 선의에 의존한다** (코어)
설계 §5.3 "생존 유닛 전원이 FLEE 판정" 의 구현이 플래그 하나뿐이고, 실제 FLEE 선택은 `fake.py` 의 분기에만 있다. 실모델이 붙으면 `abandon` 이 남고도 계속 싸운다 — 인스펙터가 거짓말한다.

**P1-2. 이탈 판정이 라벨만 바꾸고 행동은 못 막는다** (코어)
`character.py` 가 deviate 에도 `available_actions` 를 그대로 준다. 모델이 방침대로 치면 "이탈했지만 방침대로" 가 된다.

**P1-3. 1명·2명 출전이 거부된다** (트롤픽)
`content/missions.py` 가 모든 미션에 `lineup_min=3`. 기획서 §7.2 는 "A·B 단계: 로스터 5, 출전 1~3". 엔진 자체는 1·2명으로도 예외 없이 끝난다. 덤: `_default_positions` 가 1명 출전이면 그 한 명을 후열에 세운다.

**P1-4. 턴 상한 30턴째가 첫 행동 하나로 잘린다** (코어·트롤픽)
`outcome()` 이 유닛 루프 안에서 `turn >= turn_limit` 를 보고 즉시 draw 를 낸다. 30턴 행동 4개가 사라져 무승부율이 오염된다.

**P1-5. 실수·bool 포인트가 통과해 능력치가 10.5 가 된다** (트롤픽)
`allocate()` 가 `isinstance(int)` 를 안 본다. `{'str_': 2.5}` → 10.5, `True` → 1점. 문자열은 `TypeError` 라 API 가 500 을 낸다.

**P1-6. 행운이 판단 경로에 들어간다 — 도적의 무기 선택** (심사위원)
`content/classes.py` 가 `luck >= 12` 로 투척 나이프(ranged) vs 단검(근접)을 가른다. 그 한 비트가 사거리·편성·거리 페널티를 바꾼다. 기획서 §4.2 위반.

**P1-7. `decision.reason` 에 id·기계 토큰·조사 오류가 섞여 화면에 그대로 나간다** (투표 사용자)
`"조준 사격 로 vargas 를 친다."`, `"garret 를 노린다."`, `"적응: target_healer."`. 감독의 `per_unit_directive` 도 같다.

**P1-8. 가렛의 매 턴 문장이 거짓이다 — "방패 밀치기로 적 전체를 친다"** (투표 사용자)
self/guard 스킬인데 reason 이 "적 전체". P0-4 와 같은 뿌리.

**P1-9. 보스 적응이 읽기만 하고 결과가 없다** (투표 사용자·코어·심사위원)
`target_healer` 3회 반복(대상은 전열에 막혀 못 맞음), `summon_faster` 는 이미 `summon_max` 가 차서 무효. `boss_adapt` payload 에 실제 효과(before/after)가 없다. 모델의 `adapt` 응답은 코드가 이미 적용한 뒤라 장식이다.

**P1-10. 하네스가 폴백(Fake) 응답은 검증하지 않는다** (코어)
`_use_fallback` 이 `validate` 없이 돌려준다. `test_Fake_는_항상_스키마를_통과한다` 는 `character` 한 역할만 본다.

**P1-11. 승산 임계 범위 리터럴이 두 곳에 더 있다** (코어)
`core/agents/schemas.py` 의 `0.15/0.45`, `prompts.py` 의 f-string. `RETREAT_THRESHOLD_RANGE` 를 참조해야 한다.

**P1-12. 카일 도망 장면이 샘플에 없다 — 도망친 건 희생형 수녀 일레인** (투표 사용자)
생애 가중이 상수 0.2 라 카일은 만피 1턴에도 26.5% 로 이탈하고, 그 결과가 전부 DEFEND 다. 진입 화면 "딸 때문에 도망친 궁수" 카드를 이 샘플로 만들 수 없다. 덤: Fake 의 deviate reason 에 `life` 텍스트가 없다(18개 고유 reason 중 '딸' 0회).

**P1-13. 후퇴 명령을 따르는 FLEE 가 "이탈" 로 기록된다** (투표 사용자)
샘플 seq 428~431: 감독이 `"후퇴한다. 생존 우선."` 을 지시했는데 `verdict:"deviate", follows_plan:false` 이고 프롬프트는 "따르지 않기로 했다" 라고 말한다.

### P2

**P2-1. 밸런스 리터럴이 constants 밖에 있다** (코어)
`resolve.py` 상태 효과 값(guard 20·slow 2·blind 15·bless 10), `combat.py` 치명 클램프 1/95, `odds.py` 생존계수 바닥 0.3, HP 버킷 0.7/0.3 이 `visibility.py`·`prompts.py` 에 중복, `boss.py` 임계 0.5, `fake.py` 전략별 임계·HP·스태미나 임계 전부.

**P2-2. 격리 테스트의 검사 범위에 구멍** (코어)
성별 가드가 `core/runner.py`·`core/trace/` 를 안 본다. 행운 가드가 `core/agents` 를 안 본다. "표준 라이브러리만" 이 블랙리스트다.

**P2-3. 이벤트 kind·payload 가 설계 §8 표와 어긋난다** (코어)
`summon` 이 코드에만 있음. `mission_start.no` ↔ 설계 `mission_no`. `odds` 에 `faction_power` 없음. `resolution` 이 평면 대신 `strikes[]`.

**P2-4. `context` 가 단계 근거를 안 남긴다 — 어둠 -1 이 안 보인다** (심사위원)
샘플 seq 6 `wis 12 → tier 0` 이 설계 §4.6 표(12→1)와 어긋나 보인다. `tier_breakdown` 이 필요하다.

**P2-5. 행동 순서 동률 주사위가 로그에 없다** (심사위원)
가렛·일레인이 24턴 내내 동률인데 순서가 뒤집히는 이유를 인스펙터가 설명 못 한다.

**P2-6. `follows_plan` 은 모델 자기신고다** (심사위원)
코드가 방침 준수를 검증하지 않는다. `matches_directive` 를 코드로 계산해야 한다.

**P2-7. 감독 OFF 에서 프롬프트가 자기모순이고 순응 판정이 ON/OFF 동일하게 돈다** (심사위원)
"단장이 없다. 방침도 없다." 직후 "단장의 방침을 따르지 않기로 했다". E1 OFF 군의 이탈 이벤트가 방침과 무관한 수치가 된다.

**P2-8. `abandon`·`replan_trigger`·수하 `decision` 에 수치가 빠져 있다** (심사위원)
`abandon` 에 임계·forced 없음, `replan_trigger.detail` 이 문자열, 수하는 판단 근거 없음.

**P2-9. `run_start` 에 성별·배분·클래스 지정이 없고, 성별은 어디에도 관측 효과가 없다** (심사위원·투표 사용자)
`narration.voice()` 의 두 분기가 같은 문자열을 반환한다. 로스터 화면에 성별 셀렉트가 있는데 아무것도 안 바뀐다.

**P2-10. resolution.modifiers 가 무기/갑옷을 구분 못 하고 속도 페널티가 빠진다** (트롤픽)
`[['무게 미달', -20], ['힘 미달', 1.2], ['무게 미달', -10]]` — 부위도 축도 없고 명중(%)과 스태미나(배수)가 같은 열에 섞인다.

**P2-11. "마른 캐릭터에 판금" 은 제품 경로로 도달 불가** (트롤픽)
`choose_build` 가 마른 몸에 판금을 절대 안 고른다. 기획서가 반복해 드는 대표 예시가 게임에서 안 나온다.

**P2-12. 전원 자발 도주가 "lose · 사망 0 · 생존 3" 으로 집계된다** (트롤픽)

**P2-13. 출전하지 않은/없는 id 의 allocations·classes 는 조용히 무시된다** (트롤픽)
오타 `garet` 하나로 배분이 통째로 빠져도 조용하다.

**P2-14. 동어반복·느슨한 테스트** (코어)
`outcome in (네 값 전부)`, `A or B` 형태로 항상 참인 단언 3건. `ward`·`summon_every` 를 검증하는 테스트 0건.

**P2-15. 파일·함수 길이** (코어)
`core/runner.py` 375줄, `play_mission` 133줄, `resolve` 113줄, `fake._orchestrate` 80줄.

**P2-16. 서사 한 줄이 시스템 설명이거나 중복** (투표 사용자)
세라핀 `"지혜가 높아 전장을 전부 본다"` 는 마스킹 규칙 설명. 일레인 life 와 backstory 첫 문장이 완전 중복. 구울 A/B 라는 이름.

**P2-17. `run_stream` 은 스트림이 아니다 / 포트 주석이 사실과 다르다 / `content/party.py` 가 러너 내부 타입에 묶였다** (코어)
