## 라운드 1 재검 — 전부 실물로 확인됨

코어 동료가 P0 셋(재계획 트리거 · 결정론 · set 순회)과 P1 여섯(후퇴 명령 · 이탈 선택지 · 임계 단일 출처 · 폴백 검증 · 정수 포인트 · 적응 effect)을 실행으로 확인했다. 평가 담당은 프로세스 간 결정론을 세 프로세스(`PYTHONHASHSEED=0/12345/random`)에서 트레이스 해시가 같음으로 확인했다.

투표 사용자는 **문장 층이 안 고쳐졌다**고 지적했다 — 아래 P0-A·B.

## 발견과 처리

### P0-A. 서사 259줄 중 103줄에 `을(를)` 기계 토큰 — 고침
받침을 보고 조사를 고르는 함수를 양쪽에 넣었다(`core/agents/josa.py`, `frontend/lib/josa.ts`). 한글이 아닌 이름으로 끝나면 병기형으로 물러선다. 소환 유닛 이름이 `잔해 수하 1` 처럼 숫자로 끝나 조사를 고를 수 없었으므로 한글 서수(`첫째`·`둘째`)로 바꿨고, `구울 A/B` 도 `앞선 구울`·`뒤따르는 구울` 로 고쳤다. 회귀 테스트: 샘플의 모든 서사에 병기형이 0줄.

### P0-B. 화면에 영문 id 35줄 — 고침
`narrate.ts` 가 자유 텍스트(모델 사유·트리거 설명·보정 메모)에 `withNames` 를 통과시킨다. 백엔드의 Fake·보스 정책·`resolve` 의 note 도 이름을 쓴다. 회귀 테스트: 모든 이벤트의 서사에 id 0줄(예전 테스트는 카일의 decision 만 봤다).

### P0-C. E1 이 감독의 가치를 반대로 보고했다 — 고침 (평가 담당)
200시드 짝비교(McNemar)로 원인을 특정했다. 후퇴 실행 비용도, 승산 오보정도 아니었다. **집중 목표와 편성 두 줄**이었다.

- **집중 목표**: 20시드 관측으로 넣었던 "곧 죽일 수 있는 잡졸 먼저" 를 150~200시드가 뒤집었다. 바르가스가 3턴마다 수하를 부르므로 재계획마다 목표가 수하로 갈아탔고(수하 314 / 보스 107), 보스 피해 비중이 63%→44% 로 떨어져 보스 처치가 47판→8판이 됐다. 보스가 살아 있는 한 소환은 멈추지 않는다. 보스·치유자 우선으로 되돌렸다.
- **편성**: "가장 잘 때리는 사람 하나를 전열 뒤에" 로 바꿨다. 근접 적은 전열이 살아 있는 한 후열에 닿지 못하므로 전열이 방패고, 그 뒤에서 계속 때리는 사람이 판을 끝낸다. 실측: 전 근접 조합에서 전원 전열 1% vs 최고 딜러 후열 25%.
- 시도했다가 되돌린 것: 후열 근접에 명중 -15 페널티. 전 근접 파티를 이중으로 벌해 승률이 11%까지 떨어졌다 — 조합을 벌하는 규칙이 아니라 편성 판단을 재는 규칙이어야 한다.

수정 후 E1(200시드): 균등만 유의하게 이득(94% vs 74%, p<0.0001), 나머지 셋은 잡음과 구별 안 됨. **감독이 어떤 조합도 해치지 않는다.**

### P0-D. E3 지표가 적의 행동 41% 를 섞어 셌다 — 고침
`metrics_of` 가 `decision` 을 전부 셌는데 보스·수하도 같은 kind 를 낸다. 출전 명단으로 걸러 파티 행동만 센다.

### P1-E. E3 의 risk 축과 sacrifice 축이 md5 까지 동일했다 — 고침
계수가 둘 다 -0.003 이라 축이 수학적으로 구별 불가능했다. 축마다 **다른 항**을 흔들게 했다: 위험 성향은 HP 항의 배수, 희생 수용도는 아군 손실·생애 항의 배수, 협동은 평탄한 보정. 200시드 결과가 이제 세 축에서 다르게 나온다.

### P1-F. 30판은 어떤 결론도 지지하지 못한다 — 고침
`aggregate` 가 비율만 남겨 짝을 잃었다. 판별 결과를 남겨 McNemar 짝비교(ON만 이김 / OFF만 이김 / p)를 표와 JSON 에 싣는다. 기본 시드를 30 → 200 으로 올렸다(200판×4조합×2가 12초).

### P1-G. 리플레이가 유저의 성별 선택을 조용히 되돌렸다 — 고침
`run_start` payload 에 `allocations`·`classes`·`genders` 를 그대로 싣고, API 는 역산을 그만뒀다.

### P1-H. 지혜 마스킹이 화면에 한 줄도 안 나왔다 — 고침
`context` 가 통째로 접혀 있어 인스펙터의 "본 것 / 못 본 것" 에 도달할 경로가 0이었다. 가려진 것이 있는 `context` 는 접지 않고, "전부 보기" 토글도 노출했다.

### P1-I. 변화 없는 적응이 같은 문장으로 반복됐다 — 고침
`no_change` 를 서사와 인스펙터가 읽는다. 인스펙터는 "실제 변화" 행을 따로 보여준다.

### P1-J. 모르는 런 id 로 들어가면 이유 없이 "끊겼다" 만 남았다 — 고침
BFF 가 HTTP 오류를 SSE `event: error` 로 흘려 화면이 사유를 보여준다.

### P1-K. 모바일에서 인스펙터가 서사 아래로 밀렸다 — 고침
좁은 화면에서 패널이 자기 안에서만 스크롤하고(46~60vh), 줄을 누르면 인스펙터로 스크롤한다.

### P2 — 함께 고친 것
- 인스펙터가 모든 판단에 `undefinedms` 를 찍었다(latency 가 `payload.timing` 으로 옮겨졌는데 프론트가 안 따라갔다).
- 인스펙터의 승산 뷰가 옛 키(`hp_ratio`·`power`·`total`)를 읽었다 — time-to-kill 스키마에 맞췄다.
- 이벤트 kind 목록의 세 번째 사본(`BattleClient.KIND_LIST`)을 지우고 `KINDS` 를 import.
- "출정" 버튼이 fetch 예외에 영구히 잠겼다 — `try/catch`.
- 실험 차트가 390px 에서 가로로 넘쳤다 — `width="100%"`.
- 전멸한 후퇴가 `retreat` 로 집계돼 차트에서 "빠져나왔다" 로 읽혔다 — 한 명도 못 빠져나오면 `lose`.
- 환경의 거리 페널티가 후열 근접(검)에도 붙었다 — 원거리·마법에만.
- 자기에게 거는 기술이 "전장에 퍼진다" 로 나왔다 — "스스로에게 건다".
- E1 조합이 클래스만 바꾸고 배분은 프리셋을 써서 "마법사 몰빵" 의 마법사가 지능 8 이었다 — 조합마다 배분을 함께 준다.

## 보류 — 라운드 3으로

- **밸런스 리터럴이 `constants.py` 밖에 있다.** `adapters/llm/fake.py` 의 전략별 임계·HP·스태미나 문턱, `visibility.py`↔`prompts.py` 의 HP 버킷 중복. 어댑터의 정책 파라미터를 한곳에 모으는 일은 러너·프롬프트 구조를 함께 건드려야 한다.
- **`api/main.py` 가 얇지 않다.** `build_app()` 258줄에 프리셋 조립·캠페인 매핑·인터미션 정책이 섞여 있다. `content/preset.py`·`content/campaign.py` 로 내리는 작업이 필요하다.
- **런 생성에 상한이 없다.** 배포 전에 동시 런 상한(429)과 완료 세션 정리가 필요하다. **9/12 배포 전 필수.**
- **SSE 종료 센티널이 단일 소비자 전제다.** 같은 런을 둘이 보면 한쪽의 `done` 이 15초 늦다.
- **이벤트 kind·payload 가 설계 §8 표와 어긋난다.** `summon` 이 표에 없고, `mission_start.no` vs `mission_no`, `resolution` 이 평면 대신 `strikes[]`. 설계 문서를 코드에 맞춰 갱신해야 한다.
- **E2 가 승률로는 효과를 못 잡는다.** 결과변수를 적응 직후 3턴 피해량이나 보스 생존 턴으로 바꿔야 한다. E2 검증 테스트도 없다.
- **Fake 단원이 MOVE·WAIT 를 한 번도 안 쓴다.** 이탈 시 행동도 `hp<40 → FLEE / 아니면 DEFEND` 고정이라 성향이 이탈 **빈도**만 바꾸고 FLEE:DEFEND 비는 못 바꾼다.
- **`metrics_of` 가 미션 둘 이상에서 창이 어긋난다.** `party_size` 는 출전 전체, `outcome` 은 마지막 미션. docstring 에 명시해 두었지만 B단계 실험을 돌리기 전에 정리해야 한다.
- **성별이 아직 아무것도 안 바꾼다.** `narration.voice()` 의 두 분기가 같은 문자열이다.
- **`Inspector.tsx` 411줄 · `core/runner.py` 388줄 · `play_mission` 138줄** — 300줄·60줄 규칙 위반.
