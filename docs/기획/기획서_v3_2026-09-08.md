## 0. 한 줄 정의와 세계관

### 0.1 한 줄 정의

**"제약 조건 하에서 자율 판단·협업·장기계획을 수행하는 멀티에이전트 시스템 — 게임을 검증 환경(testbed)으로 사용한다."**

- 유저는 캐릭터를 조종하지 않는다. 방향을 정하고, 조합을 고르고, 결과를 관찰한다.
- 캐릭터는 성격·신체·생애에 따라 따르거나 거부한다. 행동의 누적이 성격을 바꾸고, 전장에서 도망가고 희생한다.
- 오케스트레이터는 유저가 준 로스터(좋든 나쁘든)로 최선을 찾고, 싸울 가치가 없으면 포기한다.
- **이 전부가 로그로 추적되고, 실험으로 측정된다.**

앞 절반은 게임 트레일러, 뒤 절반은 기술 문서 — 이 이중성이 프로젝트의 정체성.

### 0.2 세계관 — 1360년대, 계약이 끝난 자들

**원칙: 스토리는 시스템의 메타포다.** 설정은 규칙을 설명하기 위해서만 존재하고, 규칙에 없는 설정은 쓰지 않는다.

브레티니 조약 이후. 왕들이 휴전에 서명하자 수만 명의 병사가 실직했고, 그들은 고향으로 돌아가는 대신 중대를 짜서 남았다. 사람들은 그들을 **자유중대**라 불렀고 그건 칭찬이 아니었다.

> **왕들은 브레티니에서 휴전에 서명했다. 숲은 서명하지 않았다.**

전쟁이 멈추자 드러난 것이 있다. 십 년간 군대가 지키던 길 뒤편에서 **사람이 아닌 것들**이 자리를 넓혀 왔다. 영주는 정규군을 다시 부르지 않는다 — 자유중대가 더 싸다.

유저의 부대는 그중 가장 작은 중대다. 명단에 다섯 명이 올라 있고, 계약은 계절 단위로 들어온다. **한 계약 = 18출동.**

**마법이 없다.** 회복 주문도, 적 마법사도, 언데드도 없다. 회복은 전령관의 지혈과 봉합뿐이다. 그래서 **부상이 다음 출동으로 이월되고**, 적이 사람이 아니라서 협상도 항복도 없다. 이것이 설정이 아니라 설계인 이유는 §4.2·§5·§6 에서 드러난다 — 힐러를 넣는 순간 사망률 곡선과 자원 딜레마가 동시에 무너진다.

### 0.3 유저의 자리 — 중대 서기

> **"당신은 칼을 들지 않는다. 장부를 든다."**

계약서를 쓰고, 급료를 나누고, 누구를 내보낼지 정하고, 굴에 사람을 다시 보낼지 결정한다. 전장에는 가지 않는다.

전장에서 후방과 대열을 잇는 것은 깃발과 **뿔피리**뿐이다. 대열이 붙는 순간부터 유저는 결과를 기다린다.

**유저가 전투 중에 할 수 있는 일은 하나다 — 뿔피리. 계약 기간 동안 세 번**(§8.2).

## 3. 팀 구성 — 코어 2 + 위성 3

### 3.1 원칙
- 5명의 여유는 **코어 게임 시스템 확장에 쓰지 않는다.** 코어 상태 머신을 건드리는 기능(캠페인·랭크·PvP·관계축·반사실)은 통합 표면을 곱셈으로 늘린다.
- 여유는 **코어를 건드리지 않고 코어의 출력(로그)을 소비하는 일**에 쓴다: 평가, UI, 콘텐츠, 배포.
- 근거: 정리본 5.3 "검증 표면적을 팀의 검증 능력 이내로". 참조 사례(라이프 튜토리얼 팀)에서 실질 개발 2석 + AI 위임으로 하루 수십 버전이 나왔고, 병목은 타이핑이 아니라 검증·통합·프론트 폴리싱이었다.

### 3.2 역할
| 역할 | 담당 범위 | 첫 주 산출물 |
|---|---|---|
| **코어 A** | 규칙 엔진(순수 도메인, 유닛테스트), 하네스(JSON 스키마·검증·재시도·LLM 포트), **Fake/Replay 어댑터**, 진영 대칭 전투 엔진 | 엔진 + 로그 스키마 구현 |

## 4. 캐릭터 시스템

### 4.1 생성 — 탄생과 방향

로스터는 **지급**되고, 각 캐릭터의 **초기 방향성은 유저가 결정**한다.

```
[1] 지급     : 로스터 N명 (비전 10 / A·B 단계 5). 각자 신체 주사위 1회 굴려진 상태로 지급
[2] 관찰     : 유저가 키·체형·몸무게·(MBTI 표기)를 본다
[3] 방향 결정: 유저가 각 캐릭터에 ① 능력치 초기 포인트 분배 ② 병과 ③ 성별 을 정한다
[4] 이후     : 유저 손을 떠난다. 세부 육성·빌드는 AI, 순응 여부는 캐릭터
```

- **주사위는 탄생 1회 한정.** 신체(키·체형·몸무게)는 이후 변하지 않는다. 유일한 예외는 3.8의 부상(장애).
- 순서가 중요하다: 몸을 먼저 보고 병과와 능력치를 맞춘다. 스카우트가 선수 몸을 보고 포지션을 정하는 구조.
- **"육각형이 좋은 게 아니다."** 약탈병은 마르고 가벼운 신체가 맞다. 모든 신체가 높을 필요가 없고, 신체–병과–능력치의 **정합**이 강함을 만든다. 마른 캐릭터를 중장병으로 키우는 것도 유저 자유(트롤픽 허용, 4.3 효율 페널티로 귀결).
- **병과는 중복 가능하고, 랜덤 지정도 가능하다.** 다섯을 전부 중장병으로 뽑아도 게임은 막지 않는다(§8.1).

#### 병과 5종 — 실제 병과 (v3 확정, 마법 계열 없음)

| 병과 | 실체 | 전장 역할 |
|---|---|---|
| **중장병**(Man-at-arms) | 판금·사슬, 폴액스·롱소드. 중대에서 가장 비싼 몸 | 돌파·백병 |
| **방패병**(Pavisier) | 대형 방패(파비스), 창. 전열 유지 | 저지·엄호 |
| **장궁병**(Longbowman) | 이 시대의 결정적 병과 | 원거리 제압 |
| **약탈병**(Brigand) | 경장 보병. 척후·야습·약탈 | 정찰·측면·기습 |
| **전령관**(Herald) | 나팔·문장·사상자 확인. 종군 이발사를 겸해 **지혈·봉합**. 짐과 보급도 이들 몫 | 사기·응급·신호·운반 |

**전령관은 장식이 아니다.** 헤럴드는 실제로 전투 후 사상자를 세고 가장 잘 싸운 자를 지목했다. **뿔피리도 그가 분다**(§8.2).

전령관 없는 편성의 대가: 후퇴 신호 1턴 지연 / 부상 이월(응급 처치 없음) / 회수·운반 미션 페널티 / 공훈 판정 보너스 감소.

**이 5종에 마법 계열을 추가하지 않는다.** 회복은 전령관의 물리적 응급 처치가 전부이며, 이것이 부상 이월·정비 행동·피로 관리를 실제 압박으로 만드는 유일한 이유다.

### 4.2 능력치 6종 — "모든 속성은 판단 분기를 만들어야 한다" (정리본 3.1 원칙)

| 능력치 | 뜻 | 무엇을 바꾸는가 | 관할 |
|---|---|---|---|
| 힘 | 근력 | 물리 피해, 중량 장비 효율 | 규칙 엔진 |
| 민첩 | 몸놀림 | 명중·회피, 행동 순서 | 규칙 엔진 |
| 체력 | 버티는 힘 | HP, 스태미나, 피로 회복 속도 | 규칙 엔진 |
| 지능 (지성) | 똑똑함 | 숙련 성장률(육성 효율), 장비 운용 효율 | 규칙 엔진 |
| **지혜 (이성)** | 판단력 | **캐릭터 에이전트에 주입되는 정보의 해상도** — 낮으면 아군 상태·적 패턴·방침 의도 일부가 프롬프트에서 가려짐, 높으면 전부 보고 판단. 수읽기 깊이 | 프롬프트 조립 |
| 행운 | 운 | 실행 판정·치명타 **굴림에만** 소폭 보정. 판단 로직에는 개입하지 않음 | 규칙 엔진 |

- 지성과 이성의 분리: **지능은 수치를 올리고, 지혜는 볼 수 있는 것을 늘린다.** 구현은 프롬프트 조립 시 필드 마스킹이라 비용이 거의 없다.
- **v3 — 지능에서 "마법 위력" 을 삭제했다.** 마법이 없으므로(§0.2) 지능은 육성 효율과 장비 운용에만 걸린다. 지능이 판단 분기를 만드는 경로는 육성 층(§5)이다.
- 행운을 판단에 걸지 않는 이유: "그냥 랜덤 아니에요?"의 근거가 되고, 성향별 행동 분포 실험(10장)을 오염시킨다. 폭은 작게.

### 4.3 신체 (주사위) vs 능력치 (포인트) — 경계

| | 신체 | 능력치 |
|---|---|---|
| 결정 | 탄생 시 주사위 1회 | 유저 포인트 (초기 + 매 회차) |
| 변화 | **불변** (예외: 부상) | 성장 |
| 역할 | **효율 스펙트럼** — 이 장비가 이 몸에 맞는가 ("장착 가능하나 명중 -30%, 스태미나 2배") | **수치** — 피해·HP·명중치 |
| 항목 | 키, 체형(마른/보통/건장), 몸무게 | 힘·민첩·체력·지능·지혜·행운 |

기준: **훈련으로 변하는 것은 능력치, 타고나서 안 변하는 것은 신체.**

### 4.4 성별

- 유저가 선택한다. 키·몸무게를 보고 유저가 판단해도 된다.
- **전투·능력치·판단 엔진에 영향 0.** 표현 레이어(이름·대사 톤·서사)와 **생애 이벤트의 사유**에만 관여한다.
- 생애 이벤트에서 성별별 이탈 사유가 다를 수 있다(6.2). 단 **기대 이탈 비용(평균 이탈 턴 수)은 성별 간 동일하게 시뮬레이션으로 튠**한다(10장 실험). 성별 차이는 어떤 사유로 빠지느냐라는 서사의 차이일 뿐, 기대 비용의 차이가 아니다.
- 정리본 3.1의 "성별 제외" 결정을 위 조건부로 철회한다.

### 4.5 성향 4축과 MBTI (정리본 3.1·3.2 유지)
- 판단 축 4개: 위험 성향 / 협동 성향 / 계획 성향 / 희생 수용도 — LLM 프롬프트 관할
- 내부는 수치, 외부 표현은 MBTI 스타일. 가중치 테이블 방식(방식 B). LLM이 MBTI를 직접 해석하는 방식 A는 금지.
- **성향은 지급 시 시드로 결정, 유저 불가 (v3 확정).** 성격은 태어나는 것이고, 유저가 정하면 실험 변수가 오염된다. 유저는 MBTI 표기로만 본다.
- 상황 맥락(환경·HP·아군 상태)은 캐릭터 정의와 분리해 매 턴 주입.

## 5. 성장 시스템 — 세 층

"세부 육성은 AI"와 "유저가 포인트를 찍는다"가 모순되지 않게 층을 나눈다.

| 층 | 대상 | 결정자 | 메커니즘 |
|---|---|---|---|
| **방향** | 능력치 6종 | **유저** | 출동 종료 시 **은화** 지급 → 훈련으로 능력치 전환. **은행 가능**(모아두기), "추천 배분 수락" 버튼(단순 UI 편의, 조언 시스템 8.2와 무관) |
| **세부** | 숙련·빌드 (무기 숙련, 스킬, 전투 스타일) | **AI** | 육성 턴에서 캐릭터 신체·능력치·병과를 보고 판단. "키 작고 힘 센 중장병 → 긴 창 비효율, 워해머" |
| **통제 밖** | 컨디션·성격·관계 | **캐릭터** | 순응/거부, 생애 이벤트, 트라우마·각성 |

- 역성장(피로 누적)은 **숙련·컨디션에만** 걸린다. 유저가 찍은 포인트를 시스템이 뺏지 않는다.
- "한 명만 몰빵" 사회실험의 레버는 정확히 이 유저 포인트 배분이다.

### 5.0 보상 — 자원 3종 + 개입 1종 (v3 신설)

**총량은 계약서가 정하고, 분배는 서기가 한다.**

| 자원 | 용도 | 유저가 정하는 것 |
|---|---|---|
| **은화** | ① 훈련(능력치) ② **회수 비용**(§6.8) ③ 장비 구입 | 누구에게 · 무엇에 |
| **정비 행동** | 대원 1인당 1행동: 훈련 / 휴식 / 치료 / 여가 | 시간 제약 (§5.1 육성 턴) |
| **성물** | 판정 1회 개입 | 언제 (저장 가능) |
| **뿔피리** | 계약 기간 3회, 전투 중 즉시 이탈 | 유저의 유일한 전투 중 개입 (§8.2) |

- **은화 하나로 통합한다.** 중세 용병 서사에서 모든 것은 돈으로 환산되고, 그래야 *"토마의 회수 비용 40은 중장병 둘의 한 계절 훈련이고, 출동 한 번이다"* 같은 딜레마가 성립한다.
- **성물은 기적을 일으키지 않는다.** 판정에 advantage 를 줄 뿐이며, 이것이 마법 배제 원칙의 경계선이다.
- 피로·정신피로는 0~100 척도로 관리한다. 정신피로 임계 초과는 이탈 판단(§6.2)과 놀의 「탈주 추적」 학습 카드(§8.4)로 이어진다.

### 5.1 육성 턴 (정리본 3.5 유지)
- 유저: 카테고리 지시(교육/훈련/휴식/여가)
- 순응 판정(성격 가중치 기반 결정론적 확률) → 순응 / 부분 순응 / 거부(다른 행동)
- 실행 판정(주사위 + 컨디션 보정, 성실→advantage, 피로→disadvantage)
- 거부 시 LLM이 대체 행동 서사 생성("훈련장 대신 술집") + 결과도 파라미터로 귀결
- 유저에겐 결과만 통보, 시스템은 전부 기록 — 관찰가능성 문제의 축소판
- 연구 질문: "항상 순응하는 캐릭터가 최강인가?"

## 6. 로스터 생애 주기

캐릭터 하나의 슬롯이 겪는 상태를 한 모델로 묶는다.

```
탄생(주사위 1회) → 방향 결정(유저) → 재적
  → [쓰러짐] → [부상]   → 회복(1~2 출동 능력 저하) → 재적
             → [끌려감] → 회수 결정(유저) → 성공 시 재적 / 미지불·실패 시 상실
             → [사망]   → 충원(주사위) → 재적   ※ 사망 = 소멸
  → [이탈: 복귀 예정] → 충원(주사위) → (대체자 사망 → 신입) → 복귀(점유자 탈퇴) → 재적
  → [이탈: 영구]       → 충원(주사위) → 재적
```

### 6.0 쓰러짐 3분기 (v3 신설 — v2 의 즉사 대체)

HP 가 0 이 된 대원은 **쓰러짐(Down)** 상태가 되고, **전투 종료 시** 결과가 갈린다. HP 0 이 곧 사망이 아니다.

| 분기 | 의미 | 이후 |
|---|---|---|
| **부상** | 회복 가능 | 다음 1~2 출동 능력 저하. 전령관이 없으면 이월 폭이 커진다 |
| **끌려감(Taken)** | 굴로 끌려감. **살아 있다** | 유저가 회수 여부를 결정(§6.8) |
| **사망** | 소멸 | 부활 없음(§6.6) |

**사이클별 확률 (§4.2 사망률 곡선)**

| 구간 | 국면 | 부상 | 끌려감 | 사망 |
|---|---|:-:|:-:|:-:|
| 1~5 | 봄 · 고블린 | 97% | 3% | **0%** |
| 6 보스 | 성장기 | 85% | 13% | 2% |
| 7~11 | 여름 · 놀 등장 | 70% | 22% | 8% |
| 12 보스 | 성체 | 60% | 25% | 15% |
| 13~17 | 가을 · 오크 등장 | 55% | 25% | 20% |
| 18 보스 | 킹 | 50% | 25% | 25% |

**1~5 는 사망 0% 고정이다.** 고블린은 죽이기보다 끌고 간다 — 튜토리얼 구간에서 유저는 아무도 잃지 않고 부상과 피로 관리만 배운다. **첫 상실은 7~11 의 끌려감으로, 죽음이 아니라 선택으로 온다.**

> **v3 용어 변경**: v2 의 「포로」를 **「끌려감(Taken)」** 으로 교체한다. 몸값 협상이 성립하지 않는 대신, 대원은 살아 있는 채로 굴에 있고 유저는 **사람을 다시 보낼지** 결정한다.

### 6.1 슬롯 상태 모델
- 슬롯 필드: `점유자`, `휴직 중 원소유자`(복귀 예정 이탈 시), `점유자 유형`(원소유자 / 경력 대체자 / 신입)
- 로스터 상한은 항상 N. 대체자가 자리를 점유하므로 초과가 생기지 않는다.

### 6.2 이탈 — 이벤트가 아니라 판단
- 이탈 사유는 생애 이벤트 카테고리로 생성된다. 예: 임신·출산, 부상 은퇴, 가족 간병, 가업, 징집, 회의(懷疑)로 인한 은퇴 등. **성별별 사유 목록은 다를 수 있다.**
- 이탈 여부와 **복귀 시점은 캐릭터가 판단**한다. 고정 규칙("N턴 후 복귀")이 아니다. 희생 수용도 높고 팀 우선이면 다음 미션까지 뛰고 이탈하거나 짧게 쉬고 복귀, 자기보존형이면 즉시 이탈하고 길게, 파티 사기가 바닥이면 복귀를 앞당기는 식. → 판정 인스펙터에 "왜 이 시점에 복귀했나"가 열린다. 페널티가 아니라 **에이전트 판단 사례**.
- **기대 이탈 비용 성별 대칭**: 밸런스 시뮬레이션으로 성별별 평균 이탈 턴 수를 동일하게 튠(10장 실험 추가).
- 이탈 ≠ 사망: 경험·관계는 보존된다(감쇄는 있음, 6.5).

### 6.3 충원 — 주사위
- 사망·영구 이탈·**복귀 예정 이탈** 모두 즉시 주사위 충원.
- **주사위 높음** → 이탈자와 유사한 능력치·병과의 **경력자**. 신체·능력치·병과 고정으로 들어옴, 유저는 받기만 함.
- **주사위 낮음** → **신입**. 초기 생성 절차(4.1) 재사용: 신체 주사위 → 유저가 능력치·병과·성별 결정.
- **리롤 없음.** 있으면 운의 의미가 사라진다.
- **경력자도 팀 자산은 0.** 능력치는 비슷해도 이 파티와의 관계·신뢰·협동 패턴·상대 정보는 없다. 3.9의 명제("진짜 자원은 머릿수가 아니라 누적") 유지. 경력자도 온보딩이 필요하다.
- 주사위에 사기·승률 보정을 넣지 않는다(순수 굴림). 보정을 넣으면 죽음의 나선(3.8)이 가속된다. 순수 굴림은 바닥에서도 경력자가 올 수 있는 **회복 경로**로 작동한다.

### 6.4 대체자 (복귀 예정 이탈의 충원)
- 로스터 화면에 **대체자 표시** + "복귀 예정" 상태 표시(정확한 시점은 캐릭터 판단이라 불확정).
- **대체자에게 찍은 성장 포인트는 탈퇴 시 함께 사라진다.** 페널티가 아니라 실험 레버("언젠가 나갈 사람에게 투자하는가"). 유저가 알고 판단해야 하므로 표시가 필수.
- **대체자 사망 시 → 신입 고정 충원(주사위 없음).** 급하게 비는 자리에는 경력자가 오지 않는다. 같은 슬롯의 재충원은 신입 고정. 원소유자 복귀 시 그 신입과 교체.
- **대체자·신입의 사망도 3.8 사망 파급을 동일하게 받는다** — 사기 하락, 목격 트라우마, 생존율·피폐도 카운트. 빠지면 "대체자는 소모품" 전략이 최적이 된다. 그것도 사회실험이지만 시스템이 벌점을 안 주면 실험이 아니라 허점.
- 양면성은 그대로 둔다: 대체자가 죽고 신입이 들어와 전화위복이 될 수도, 한 자리에서 신입이 연쇄로 죽을 수도. **슬롯당 사망 횟수 분포**를 밸런스 시뮬레이션에서 확인해 발생하되 지배적 경로는 아니게 튠(10장).

### 6.5 복귀
- 원소유자가 복귀 → 현재 점유자(경력 대체자 또는 신입) 탈퇴.
- 능력치 유지. 관계·신뢰는 공백 기간에 비례해 감쇄. 첫 1~2 미션은 신인 보정보다 약한 **재적응 보정**.
- **성격 변화 트리거를 복귀 시점에 건다.** 출산 후 위험성향·희생수용도 이동 등 — 3.3 MBTI 변화 카드("카일이 변했다")가 가장 개연성 있게 발생하는 지점.
- 대체자 퇴장 서사는 LLM 한 줄 + 결산 리포트에 활약 기록 보존.

### 6.6 사망 (정리본 3.8 유지)
- 완전 소멸, 부활 없음. 장애(물리 제약 영구 변경), 트라우마(판단 축 영구 보정), 사기 하락, 관계 파급.
- 죽음의 나선 경고와 회복 경로(각성 분기, 휴식 가치, 장애 재적응, 멘토링) 유지.

### 6.7 이벤트 스키마 — effect 타입 (확정)
```
파라미터 변경 | 결장(N턴) | 이탈(복귀 예정 / 영구) | 충원(주사위 / 신입 고정) | 복귀(점유자 탈퇴) | 사망
```
카테고리 스키마 고정 + effect 범위 제한 — 자유도는 서사에, 안정성은 스키마에(정리본 3.4 유지).

**v3 추가**: `쓰러짐(부상 / 끌려감 / 사망)` · `회수(성공 / 실패)` 를 effect 타입에 더한다.

### 6.8 회수 — 끌려간 대원을 다시 데려오는가 (v3 신설)

**몸값은 은화만 태우지만, 회수는 은화와 출동 슬롯을 동시에 태운다.** 딜레마가 2축이 된다.

| 항목 | 내용 |
|---|---|
| **회수 비용** | 대원의 누적 투자 은화 × 0.6 (안내인·횃불·사냥개) |
| **추가 비용** | **출동 슬롯 1** — 해당 사이클의 미션 하나가 회수 출동으로 대체된다 |
| **지불 시** | 회수 미션 개방. 성공 시 복귀, 정신피로 +25, 관계 신뢰 대폭 상승 |
| **회수 실패 시** | 은화·슬롯 소모 + 대원 상실. 적에게 학습 카드는 제공됨 |
| **미지불 시** | 영구 상실 + 보스에게 **「섭식」 카드 1장**(§8.4) + 18회차에 장비가 오크에게(§8.5) |
| **기한** | 다음 보스전까지. 넘기면 자동 미지불 처리 |

**회수는 보장된 거래가 아니다.** 돈을 내도 실패할 수 있고, 실패하면 계약 진도까지 잃는다. 이것이 몸값과의 결정적 차이이며, 유저의 자원 결정이 곧 3회차 뒤 보스의 강함이 되는 연결 고리다.

**전령관이 회수 성공률을 좌우한다** — 흔적 판독으로 끌려간 대원의 위치를 추정한다(§4.1).

## 7. 미션·캠페인 구조

### 7.1 계약 = 18출동, 3사이클 (2026-09-09 개정)

**한 계약은 18출동이다.** 일반 15 + 보스 3. 보스 하나당 일반 **5판**이 앞에 붙는다.

```
[1][2][3][4][5]      ⟦6 · 성장기⟧   봄 · 고블린 · 사망 0%
[7][8][9][10][11]    ⟦12 · 성체⟧    여름 · 놀 등장 · 끌려감 본격화
[13][14][15][16][17] ⟦18 · 킹⟧     가을 · 오크 등장 · 결전
```

**보스 셋은 다른 놈이 아니라 같은 놈이 자란 것이다**(§8.4). 일반 구간은 준비이자 보급로다 — 은화와 정비 행동을 모아야 보스를 상대할 스펙이 된다.

**왜 4판이 아니라 5판인가.** 사이클 하나 안에서 **생애주기가 한 바퀴 돌아야** 한다(§6) —
누가 떠나고, 주사위로 충원하고, 그 사람이 한두 판 뛰어 보고, 원소유자가 돌아온다. 4판으로는
떠난 다음 판에 바로 보스전이라 대체자가 검증될 자리가 없다. 5판이면 이탈 → 충원 → 적응 →
(복귀) 가 보스전 앞에서 닫힌다.

**에피소드 길이는 여전히 파라미터다.** 18출동 구조를 유지한 채 A·B 에서 N 만 낮춰 배포한다.

| 단계 | N | 구조 |
|---|---|---|
| A 제출본 | **1~2판** | 12장 절단선 표 참조. 18출동 중 일부를 잘라 낸다 |
| B 데모데이본 | **5~6판** | 봄 사이클 전체 + 6회차 보스전. 학습 카드가 실제 로그에서 생성되는 것을 시연 |
| C 정식 | **18판** | 3사이클 전체, 4종 전체, 보스 3형태, 18회차 전리품 편제 |

**호출량 완화 장치** (전투 1판 = 100~300 호출, 15판 완주 시 2,000~4,500)
- 유형별 턴 예산 차등: 정찰 3~5 / 교전 6~8 / 호위 8~10 / 보스 12~15
- 정원이 곧 호출 배수 → 정원 5 미션은 사이클당 1회로 제한
- 비전투 구간은 규칙 엔진 + 서사 1회 호출로 처리
- **적 개체 판단에 LLM 을 쓰지 않는다.** 종별 전술 지문은 규칙 엔진으로 구현하고, LLM 은 **보스의 카드 운용 판단에만** 쓴다

네 장치로 계약 기간 호출량이 약 45% 줄어든다.

### 7.1a 미션은 12개를 손으로 만들지 않는다 — 3축 조합

미션은 **목표축 · 환경축 · 제약축** 3축의 조합으로 생성한다. 4슬롯 골격(정찰 A / 교전 B / 호위 C / 소탕 D)에 사이클별 등장 종을 끼워 넣는다.

**적 4종은 각자 골격 하나를 부순다.**

| 종 | 전술 지문 | 부수는 슬롯 | 유저에게 시험하는 것 |
|---|---|:-:|---|
| **고블린** | 다수·매복·함정. 열세를 감지하면 도주하고 다시 모인다 | D 소탕 | 광역 처리, 피로 관리, 추격 손익 |
| **놀** | 기동·측면. **부상자와 낙오자를 우선해서 문다** | C 호위 | 보호 대상 지정, 희생 수용도 |
| **오크** | 소수 정예. 정면 돌파, 개인 화력. 전리품을 걸친다 | B 교전 | 방패병의 값, 저지 판단 |
| **미노타우루스** | 위 셋을 거느린다. 3형태로 성장 | 전부 | 보스 |

**언데드·악마·이형·적 마법사를 넣지 않는다.** 취향이 아니라 에셋 문제다 — 상태 스프라이트 배증, 64×64 판독 불가, VFX(=애니메이션) 필요. 고블린·놀·오크·미노타우루스는 전부 살과 뼈라 정지 스프라이트 + 상태 오버레이만으로 성립한다.

### 7.1b 결과 5등급 (v3 신설)

| 등급 | 판정 |
|---|---|
| 완전 성공 | 주 목표 + 부가(시신·장비 회수, 굴 위치 확보) |
| 성공 | 주 목표 |
| **철수** | 목표 미달, 전원 생환. **중대장의 후퇴 판단 또는 뿔피리** |
| 실패 | 퇴각, 부상·끌려감 발생 |
| 참사 | 사망 발생 |

**「철수」가 벌점이 아닌 것이 핵심이다.** 승산 붕괴를 읽고 물러난 판은 실패가 아니다. 포기 판단을 시스템이 처벌하면 §8.3 이 죽는다.

- 2판이 최소인 이유: 인터미션이 존재해야 육성·이벤트가 있고, 이벤트 이후 전투가 있어야 인과가 닫힌다. 1판·2판이 정리본 4.3의 "끝까지 싸우는 판 vs 포기하는 판" 대비이고, 적응 OFF/ON이 실험 1번을 플레이 안에서 보여준다.
- 3판을 안 하는 이유: 두 번째 인터미션이 보여줄 성격 변화 시스템은 C단계. 전투 1판 = 100~300 호출.
- 러너는 처음부터 "미션 N개 + 인터미션" 구조로 짜고 N만 바꾼다.

### 7.2 출전 인원 — 미션별 가변 (확정)
- 미션마다 출전 가능 인원이 다르다(예: 1, 3, 4, 5, 전원). **유저가 조합을 선택**한다.
- A·B 단계: 로스터 5, 출전 1~3. C 단계: 로스터 10, 출전 1~10.
- **전원 출전 미션은 활성 에이전트 수 = 호출 배수.** C단계에서도 빈도 제한. 비용 통제 원칙(출전·육성 중인 캐릭터만 에이전트화, 벤치는 데이터) 유지.
- "한 명만 계속 키우면 나머지는 실력이 부족해 나중에 죽는다" — 인원 제한 가변 + 참여 편중도·과로도 지표(3.14)가 이 사회실험을 채점한다.

### 7.3 PvP — 위치 이동
- **플레이어 미션으로는 C단계.** 3.12의 정당화(랜덤 강제·조언 없음·train/test 분리·육성 A/B)는 전부 캠페인 구조에 의존하므로 2판 에피소드에서는 존재 이유가 없다.
- **평가 도구로는 A단계부터.** 파티 vs 파티 자동 대전은 사람이 안 껴도 돌아가는 유일한 전투 → 성향 분포 실험, 밸런스 튠, 조합별 오케스트레이터 실험의 데이터 생성기.
- 전제: 코어 A가 규칙 엔진을 **진영(faction) 대칭**으로 짠다. 보스 = "유닛 1개 + 고정 정책 진영". 보스전과 PvP가 같은 코드 경로.

### 7.4 로스터 규모
- A·B: **5명 / 출전 3**. 편성 판단(선택하지 않은 캐릭터가 있어야 편성이 성립)과 5C3=10 조합의 트레이드오프가 성립하는 최소. 5명 프로필은 데모 장면별 요구 성향(희생형·가장형·수읽기형·보수 기준선·중갑)에 대응한다 — 통합시나리오 §3 의 토마·마르탱·오드·질·아녜스.
- C: 5명 유지. 18출동 안에서 사망·끌려감·충원이 돌면 인원이 아니라 **교체율**이 서사를 만든다. 로스터 크기는 설정값이라 나중에 늘릴 수 있다.

## 8. 오케스트레이터와 조합 선택

### 8.1 유저의 조합 = 시험 문제, 오케스트레이터의 답안 = 편성·작전
- 5명(10명) 전부 전사도, 균등 분배도 유저 자유. 게임은 막지 않는다(트롤픽 완전 허용, 3.10 유지).
- 오케스트레이터는 **받은 패로 최선을 다한다.** 힐러가 없으면 속공, 습지면 경장 중심. 신체 주사위 덕에 "전사 10명"이 복사본 10개가 아니라 서로 다른 10명이 되어 역할 분담이 가능하다.
- 오케스트레이터가 평가받는 것은 좋은 조합에서의 승률이 아니라 **나쁜 조합에서의 회복력**.

### 8.2 뿔피리 — 유저의 유일한 전투 중 개입 (v3 신설)

**계약 기간 동안 세 번.**

- **불면**: 즉시 전원 이탈. 전멸은 피하지만 목표는 실패하고 보수는 없다. 결과 등급 「철수」.
- **불지 않으면**: 중대장이 스스로 판단한다. 물러날 줄 아는가 — **그것이 이 중대장이 증명해야 하는 것이다**(§8.3).
- **뿔피리는 전령관이 분다.** 전령관이 편성에 없으면 신호가 1턴 늦는다.

**세 번인 이유는 설정이 아니라 설계다.** 무한이면 유저가 조종하는 게임이 되고(§0.1 위반), 0 이면 관전이 된다. 세 번이면 매 판 "지금인가"를 묻게 된다.

이 장치가 만드는 실험이 **E7**(§10.1) 이다 — 유저의 뿔피리와 중대장의 자율 후퇴 중 어느 쪽 손실이 적은가. **"AI 가 사람보다 물러날 때를 잘 아는가."**

### 8.2a 조언 — v2 원설계 유지 (확정)
- 조언(추천 조합 + 승산 추정 + 근거)은 **희소**하게 발동: 미션 몇 회차 이후 + 승산 임계선 이하일 때 낮은 확률.
- 유저는 무시하고 강행 가능. 경고는 결과와 무관하게 로그에 남는다.
- 부수 효과: [조언 없음 / 수용 / 무시] 3그룹 자연 형성.
- (미확정 옵션, 14장) 승산 추정치를 정보로 상시 표시하고 개입(경고)만 희소로 분리하는 안.

### 8.3 판단 구조 (정리본 4장 유지)
- 2층: 전략 층 오케스트레이터(전투 시작 + 급변 시) / 전술 층 캐릭터 에이전트(매 턴, 방침 이탈 가능)
- 재계획 트리거: 캐릭터 이탈, 승산 임계선 붕괴, 적응 감지, 환경 변화
- 포기 판단: "어떻게 이기는가" 이전에 "싸울 가치가 있는가"
- 승산: 계산은 코드(휴리스틱), 판단은 LLM
- 환경 시스템: 규칙 엔진의 수정자, 편성 때 환경을 읽는 장면
- 적응형 상대: in-context 적응(한 판 안) + **판을 넘는 학습**(§8.4). C단계에서 랭크별 플레이북 축적.
- **최소 교전 턴 하한**: 중대장은 즉시 포기하지 않는다. 보스전 8턴 / 일반 3턴을 싸운 뒤에야 "싸울 값어치가 있느냐"를 묻는다. 하한이 없으면 첫 턴에 물러나는 것이 최적해가 되어 포기 판단이 무의미해진다.

### 8.4 적은 어떻게 강해지는가 — 학습 카드 4대 출처 (v3 신설)

**판타지 초능력이 아니다. 그것은 유저가 남긴 것을 먹고 자란다.**

| 종 | 출처 | 발생 조건 | 유저의 차단 수단 |
|---|---|---|---|
| **고블린** | **척후 관찰** | 정찰 미션 실패 / 고블린 척후 미격퇴 | 해당 미션 성공 |
| **놀** | **탈주 추적** | 정신피로 임계 초과 대원의 이탈 → 숲에서 잡힘 | 휴식·급료 배분 |
| **오크** | **전리품** | 미션 후 시신·장비 미회수 | 회수 조건 달성(전령관 필요) |
| **미노타우루스** | **섭식** | 끌려간 대원을 **회수하지 않음**(§6.8) | 은화 + 출동 슬롯 지불 |

**유저가 학습을 억제하는 수단이 전부 자원 결정과 연결된다.** 은화를 회수에 쓸 것인가 훈련에 쓸 것인가, 지친 대원을 쉬게 할 것인가 내보낼 것인가 — 이 선택들이 곧 다음 보스의 강함이다.

**보스 3형태는 진화 트리가 아니라 유저의 실패 기록이다.**

| 형태 | 회차 | 카드 슬롯 | 학습 범위 |
|---|:-:|:-:|---|
| 성장기 미노타우루스 | 6 | 3 | 1~4 에서 **가장 빈번한** 패턴만 |
| 성체 미노타우루스 | 12 | 5 | 누적 + **회피 봉쇄**(안 쓰는 전술을 강요하는 지형·조건) |
| 미노타우루스 킹 | 18 | 7 | 누적 + **개인 단위 대응** + 전리품 편제 |

**생성은 결정론 + LLM 2층이다.**
```
[집계 · 코드]  전투 로그 → 패턴 지표 7종 → 상위 N개
[매칭 · 코드]  카운터 카드 풀(10~12장)에서 결정론적 선택
[전술 · LLM]   보유 카드를 언제 어떻게 쓸지 in-context 판단
```
**패턴 지표 7종**: 교전 개시 거리 / 타겟 집중도 / 템포 / 병과 편중 / 특정 대원 의존도 / 응급·보급 소모 시점 / 후퇴·뿔피리 빈도

카드는 보스전 시작 시 인스펙터에 펼쳐지고 **출처 라운드·출처 인물·출처 종**이 링크된다(§11.2).
> *"이 보스는 당신이 굴에 두고 온 그 궁수에게서 이걸 배웠습니다."*

### 8.5 그것에게는 이름이 없다 (v3 신설)

미노타우루스는 고유명을 갖고 시작하지 않는다. **대원들은 그것이 처음 데려간 사람의 이름으로 그것을 부른다.**

- 첫 「끌려감」이 발생한 대원의 이름이 그대로 보스 호칭이 된다 — "토마를 데려간 것"
- **회수에 성공했더라도 호칭은 남는다.** 대원들은 잊지 않는다
- 유저마다 보스 이름이 다르다. 로그에서 생성되므로 구현 비용은 문자열 하나

**18회차 전리품 편제**: 회수하지 않은 장비가 실제로 적에게 장착된다. "토마의 장궁을 든 오크." 진영 대칭 엔진(§7.3)을 그대로 쓰므로 신규 에셋 0 장이다.

## 10. 평가(Evaluation) 체계

### 10.1 A·B 단계 실험
| # | 실험 | 검증 대상 | 단계 |
|---|---|---|---|
| E1 | **조합별 오케스트레이터 ON/OFF** — 조합 3~4종(중장병 몰빵/균등/방패병 몰빵/전령관 없음) × ON vs OFF 승률 | 오케스트레이터의 가치 = 나쁜 조합에서의 승률 회복 | A(1개) / B |
| E2 | 보스 적응 ON/OFF | 적응의 효과. B단계에서는 1판/2판이 그대로 이 대비 | B |
| E3 | 성향별 행동 분포 — 같은 전투, 성향 수치만 교체 | 다양성 = 검증된 판단 분기 | B |
| E4 | 모델 벤치마크 — 로컬 1 + API, 역할별 유효율·지연·비용 | 모델 선정 근거 | B |

| **E7** | **뿔피리 사용 시점** — 유저의 뿔피리 vs 중대장의 자율 후퇴, 어느 쪽 손실이 적은가 | **"AI 가 사람보다 물러날 때를 잘 아는가"** (v3 신규) | B |
| **E8** | **회수 결정과 완주율** — 회수를 자주 하는 유저와 포기하는 유저의 18회차 도달률·보스 강도 비교 | 자원 딜레마가 실제로 양방향인지 (v3 신규) | C |

- E1이 "그냥 랜덤 아니에요?"와 "오케스트레이터가 실제로 도움이 되나요?"에 동시에 답한다. 자동 대전(7.3)으로 돌린다.
- **E7 이 이 프로젝트의 명제를 직접 잰다.** 유저가 뿔피리를 쥐고도 안 불었을 때 중대장이 스스로 물러나는가.
- 평가 스크립트는 초기에 구축해 전 실험에서 재사용. **평가 하네스는 리팩터링 회귀 안전망이다.**

### 10.2 C 단계 실험 (정리본 7장 14개 유지 + 추가 2건)
- 원 목록 유지: 2×2 ablation, 이벤트 반응 분기, 순응률·성장 궤적, 조언 3그룹, 반사실, 캘리브레이션, 시드 분산, 육성 A/B→PvP, 밸런스 시뮬레이션, 자기대전 랭크, 평가자 일관성, 5축 분포.
- **추가 ⑮: 기대 이탈 비용 성별 대칭 검증** — 성별별 평균 이탈 턴 수 분포. 심사 질문 "여캐가 불리한가"의 답.
- **추가 ⑯: 슬롯당 사망 횟수 분포** — 신입 연쇄 사망 경로의 빈도. 죽음의 나선 감시.
- **추가 ⑰(E5): 배분 정책 3그룹** — 집중/균등/보정별 완주율·5축 분포.
- **추가 ⑱(E6): 패턴 분산도 vs 보스 강도** — 전술 다양성 지표와 학습 카드 유효도의 상관.
- **밸런스 목표**: 계약 기간 완주율 60~70%, 평균 사망 1.5명, 회수 미션 성공률 60~70%.

### 10.3 캠페인 평가 (정리본 3.14 유지, C단계)
- 5축(생존율·피폐도·행복도·성격 변화도·성장율) 랭킹, 평가 2층 구조(지표 계산층 코드 + 평가 에이전트 LLM).
- **대체자·신입 사망은 생존율·피폐도에 동일 카운트**(6.4).
- HR/조직 언어 보류, 전이 슬라이드 한 장 — 유지.

## 11. 데모 / UI

### 11.1 구현 범위 (정리본 8.1 유지)
- 그래픽·액션 없음. 대사 + 흐름 + 내부 판정값. 정체는 **에이전트 트레이스 뷰어**.
- 참조 사례의 교훈: 프론트 폴리싱은 점수에 기여하지 않는 블랙홀이 되기 쉽다. 3패널 뷰어 밖의 연출은 하지 않는다.

### 11.2 3패널 UI (정리본 8.2 유지)
- A: 서사 스트림 + 판정 인스펙터 2패널. B: 상태 대시보드 추가.
- 원칙: 왼쪽에서 일어나는 모든 일이 가운데서 설명 가능.
- **추가: 로스터 화면에 대체자·복귀 예정 표시**(6.4). **투표 사용자용 진입 화면** — 30초 안에 "뭐가 신기한지" 전달(콘텐츠·발표 담당).
- **v3 추가 ①: 뿔피리 버튼.** 전투 화면에 상시 노출, 잔여 횟수 표시. 유저가 "내가 뭘 할 수 있는지"를 30초에 안다.
- **v3 추가 ②: 학습 카드 패널.** 보스전 시작 시 카드가 펼쳐지고 각 카드에 출처 라운드·인물·종이 링크된다(§8.4). 보스 적응이 기술 차트가 아니라 **죄책감**으로 전달되는 지점.
- **v3 추가 ③: 회수 결정 화면.** 수습 단계에서 은화·출동 슬롯 비용과 성공률 미보장을 명시한다.

### 11.3 데모데이 10분 구성
1. 로스터 5명 관찰 → 유저 조합 선택(트롤픽 예시 1개 언급)
2. 1판 — Replay 어댑터로 빨리감기, 편성 판단 장면만 정지
3. 인터미션 — 거부 장면 **실시간**("휴식 지시 → 전투광이 몰래 훈련장"), 생애 이벤트 + 파라미터 diff
4. 2판 — 이탈·재계획·승산 붕괴·포기 구간 실시간, 인스펙터 개봉
5. 실험 차트 E1·E2 → 전이 슬라이드 1장(장애 대응) → 로드맵(C단계)
- 시드 고정·가속은 명시(정직성 원칙).
