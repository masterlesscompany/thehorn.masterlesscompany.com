- **로스터와 적을 통합시나리오의 것으로 바꿨다**
  로스터 다섯을 토마·마르탱·오드·질·아녜스로 교체했다. 성향 4축은 시나리오 §3
  서술대로 새로 잡았다(2026-09-08 팀 결정 ⑦). 데모 장면 다섯은 그대로 대응한다 —
  희생형 토마, 가장형 아녜스, 수읽기형 오드, 보수 기준선 질, 중갑 마르탱.

  성별은 아녜스·오드가 여성이다(결정 ⑩). 프랑스어 이름 관례를 따랐고, 기획서
  §4.4 대로 엔진 영향은 0 이다.

  병과 표기를 중세 명칭으로 바꿨다 — 중장병·방패병·장궁병·약탈병·전령관.
  코드 키는 영문 그대로다(결정 ⑨). 이름만 바꾸는 대규모 리팩터링을 한 번 더
  하지 않는다.

  적을 고블린·놀·성장기 미노타우루스로 갈아 끼웠다(결정 ⑪). 구울과 썩은 사제는
  언데드라 v3 §2.3 의 배제 대상이고, 바르가스는 골렘이라 "전부 살과 뼈다" 에
  걸린다. 각 종이 4슬롯 골격 중 하나를 부순다 — 놀은 부상자부터 문다.

  미션을 6회차 야습 + 5회차 보스전 두 판으로 바꿨다(결정 ①). 회차 번호가 순서와
  어긋나는 것은 의도다. 15출동 중 어느 판을 잘라 냈는지가 보이는 편이 낫다.

  한 판만 도는 경로(MISSIONS_SINGLE)를 따로 뒀다. API 가 intermission 을
  len(missions) > 1 로 켜는데, A단계가 두 판이 되면서 한 판 요청까지 인터미션
  입력을 기다리다 멈췄다.

  추천 배분에서 토마의 힘을 1 올렸다. 장궁이 최소 힘 9 를 요구하는데 8 이었다.
  무게등급 미달(마른 몸 vs 등급 2)로 인한 명중 -10 은 그대로 둔다 — 시나리오가
  정한 체형이고, 그것이 효율 스펙트럼이다.

  테스트의 하드코딩된 성향 수치를 로스터에서 읽도록 바꿨다. 로스터가 또 바뀌어도
  안 깨진다.

  트레이스 샘플을 시드 11 로 다시 만들었다. flee·abandon·casualty·boss_adapt 가
  한 판에 다 나오는 시드다.

  스프라이트를 지웠다. 인물이 전부 바뀌어 다시 만든다.

  검증: ruff, pytest 383, 시드 교차 결정론, E1 스모크, 프론트 22 + tsc.
