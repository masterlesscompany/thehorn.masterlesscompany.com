- **화면에 뿔피리·회수·호칭을 붙이고, 판이 사람 속도로 흐르게 했다**
  백엔드에 뿔피리·회수·호칭이 다 들어왔는데 화면에서 누를 수가 없었다.
  "버튼 하나로 30초에 전달된다" 는 뿔피리의 근거가 버튼 없이는 성립하지 않는다.

  뿔피리 버튼은 잔여 횟수를 ●●○ 로 보여주고 한 번 확인을 받는다. 되돌릴 수
  없는 행동이라 실수로 눌리면 판이 끝난다.

  회수 패널은 끌려간 사람이 생기면 뜬다. "답하지 않으면 전원 미지불" 을 화면에
  적었다 — 몰라서 당하는 건 판단이 아니라 함정이다.

  보스 호칭이 붙으면 화면 위에 남는다. 「토마를 데려간 것」.

  실물로 돌려 보고 결함 둘을 찾았다.

  뿔피리를 세 번 누르면 횟수만 3→0 으로 닳고 신호는 하나였다. 이미 울린
  신호가 안 닿았으면 거절한다.

  인터미션 중에 분 뿔피리가 묵혀 있다가 다음 판 1턴에 터졌다. 전투 중
  개입인데 전투 밖에서 받았다. 인터미션·회수 결정 중에는 거절한다.

  그리고 더 큰 것 하나. **Fake 는 한 판을 수백 ms 에 끝낸다.** 뿔피리를 누를
  시간이 없을 뿐 아니라 서사가 한꺼번에 쏟아져 전투가 펼쳐지는 걸 볼 수도
  없다. 유저의 유일한 전투 중 개입이 물리적으로 불가능하면 그 기능은 없는
  것과 같다.

  속도 어댑터를 포트에 끼웠다. core 는 잠들지 않는다 — 규칙 엔진은 시간을
  모른다. RPG_PACE_S 로 조절하고 배포 기본값은 0.2 다. 실모델은 이미 느리므로
  0 을 준다. 리플레이도 같은 속도로 흐른다.

  확인: 속도를 켜고 돌리니 2초 뒤에도 판이 살아 있었고, 뿔피리를 누르자
  4턴에 전원 셋이 물러나 「철수」 등급으로 끝났다.

  검증: ruff, pytest 425, 프론트 22 + tsc.
