- **QA 1차 수정 — P0 넷과 데모를 막던 P1 다섯을 고쳤다**
  QA 라운드: docs/qa/2026-09-09-v3-rework.md

  페르소나 다섯이 P0 6 · P1 21 · P2 22 를 찾았다. 이번 커밋은 P0 A~D 와
  데모를 막던 P1 다섯이다. E·F(실험 지표·18출동 구조)는 다음 커밋이다.

  투표 사용자가 처음 보는 화면 전체가 없는 것들을 팔고 있었다 — 카일·
  바르가스·구울·힐러. 셋 다 v3 에서 지운 것이다. 3장면을 v3 훅으로 갈고,
  미션 이름은 API 가 내려주게 해 다음에 콘텐츠가 바뀌어도 화면이 따라간다.

  결산이 거짓말을 했다. 토마가 굴로 끌려간 런에서 "쓰러짐: 없음" 이라고
  적었다 — v3 는 HP 0 이 사망이 아닌데 dead 를 쓰러짐이라 불렀다. 5등급을
  제목으로 올리고 부상·끌려감·사망을 갈랐다.

  뿔피리 가드가 여전히 새고 있었다. 어제 인터미션 플래그로 막았다고 했는데,
  훅이 지시를 받은 직후 플래그를 지우고 그 다음에 LLM 을 돌아 그 사이 창이
  열려 있었다. 트롤픽이 2회 연속 재현했고 보스전이 1턴에 끝났다. 세션 플래그
  대신 러너가 판 경계를 알리게 했다(BattleGateFn). 재검에서 막혔다.

  리플레이가 다른 판을 만들고 있었다. 모델 판단만 되감고 뿔피리·회수를 비워
  둬서 원본이 「철수」로 끝난 판이 「패배」로 끝났다. "같은 시드 = 같은 판" 이
  유저 입력이 낀 판에서 깨진 것이다. 트레이스에 재료가 이미 있어(horn 의 turn,
  recovery 의 member·paid) 그것으로 훅을 합성했다. 재검에서 이벤트 수까지 일치.

  카드 3장 중 2장이 죽어 있었다. 「사거리」는 호출부가 ranged_ids 에 빈 집합을
  박아 둬서 영원히 안 나왔고, 「섭식」은 forsaken 이 정의상 이 판에 없는 사람이라
  100% 무효였다. 그런데 화면은 "이 보스는 당신이 굴에 두고 온 그 궁수에게서
  이걸 배웠습니다" 라고 단언했다. 섭식은 이제 병과를 계승한다 — 그것이 배운
  것은 사람이 아니라 그 병과를 상대하는 법이다.

  단위 테스트가 둘 다 못 잡았다. 인자를 직접 넘겨서 초록이었다. 러너를
  통과하는 테스트를 새로 붙였다.

  README 와 「백엔드 꺼짐」 화면이 알려주는 실행 명령이 ModuleNotFoundError 로
  죽었다. 클린 아키텍처 재배치 때 Dockerfile 만 고치고 이 둘을 놓쳤다 —
  백엔드가 꺼졌을 때 심사자가 보게 될 유일한 안내였다.

  검증: ruff, pytest 444, 프론트 22 + tsc. 뿔피리·리플레이는 실물 재현으로 재검.
