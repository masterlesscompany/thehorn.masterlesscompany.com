- **클래스를 개편했다 — 마법사를 빼고 방패병을 넣고, 성직자를 음유시인으로 바꿨다**
  역할이 흐릿했다. 전사가 방패도 들고 딜도 했고, 마법사는 궁수와 겹쳤다.
  막는 쪽(방패병) · 때리는 쪽(전사·궁수·도적) · 살리는 쪽(음유시인)으로 가른다.
  E1 이 조합의 좋고 나쁨을 재는 실험이라, 조합이 선명해질수록 실험이 강해진다.

  방어/공격을 행동 금지로 만들지 않고 수치로 갈랐다 — 기획서 §4.3 "'장착 불가'
  대신 페널티" 와 같은 원칙이다. 방패병은 무기 피해 4~10 에 스킬이 전부 피해 0,
  전사는 13~16 에 스킬이 전부 공격이다. 방패병에게 도끼를 쥐여주는 트롤픽도
  막지 않는다. 방어 가치는 이미 있는 전열 차단(resolve.py 의 reachable)에서
  나오므로 엔진을 건드리지 않았다.

  세 가지는 코드를 읽고 나서 설계를 바꾼 것이다.

  스킬 이름 "치유"·"축복" 을 그대로 뒀다. boss.py 가 has_skill("치유") 로 치유자를
  찾아 적응하고 fake.py 도 같은 문자열을 쓴다. 이름을 바꾸면 보스 적응(E2)이
  조용히 깨진다. 음유시인의 색은 북·류트와 서술이 낸다.

  마법사의 화염구·서리 결계를 그냥 지우면 resolve.py 의 전체피해·전체둔화 분기가
  죽는다. 전사의 휩쓸기와 방패병의 전열 압박으로 옮겨 살렸다. 엔진이 아는 효과
  아홉이 전부 누군가에게 쓰이는지 테스트로 강제한다.

  성표와 로브는 남겼다. content/monsters.py 의 썩은 사제가 쓴다.

  세라핀 자리에는 베른 하이트(방패병)가 들어온다. 세라핀이 갖고 있던 수읽기형
  데모 슬롯(계획 +80)을 승계한다 — 안 그러면 기획서 §7.4 의 다섯 장면 매핑이
  깨진다. 가렛은 방패를 내려놓았으므로 배경담도 함께 고쳤다.

  E1 의 "마법사 몰빵" 은 "방패병 몰빵" 이 됐다. 전원 방어형이라 승률 0% 다 —
  이길 수 없는 조합에서 단장이 무엇을 하는가를 보는 데 더 선명하다.

  트레이스 샘플 시드를 1 에서 9 로 바꿨다. 개편 뒤 시드 1 은 승리로 끝나
  카일의 이탈 장면(flee·abandon)이 샘플에서 사라졌다.

  검증: ruff, pytest 368, 시드 교차 결정론, E1 스모크, 프론트 22 + tsc.
