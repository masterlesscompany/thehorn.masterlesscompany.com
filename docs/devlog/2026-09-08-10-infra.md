- **README 를 개편 뒤 상태로 맞췄다 — E1·E3 재측정 · 구조 갱신**
  E1·E3 표가 개편 전 측정치였다. 조합 이름만 바뀐 게 아니라 밸런스가 통째로
  달라졌다 — 가렛이 장창으로 때리고 베른이 탱킹한다. 옛 숫자를 두면 거짓이라
  200시드로 다시 쟀다.

  숫자가 바뀌었고, 하나는 불리한 방향이다.

  단장의 이득이 가장 큰 자리가 "힐러 없음" 으로 옮겨갔다 — 26% → 84%.
  치유가 없으면 편성과 집중 목표가 곧 생존이고 그것이 단장이 하는 일이다.

  전사 몰빵에서는 단장이 오히려 손해다(94% → 78%, p<0.0001). 이전 README 는
  "나쁜 조합에서 해를 끼치지 않는다" 고 적었는데 더는 사실이 아니다. 감추지
  않고 원인 가설과 함께 적었다 — 편성 규칙이 "가장 잘 때리는 하나를 전열 뒤에"
  인데 전원 근접이면 앞의 둘이 먼저 무너지고 판이 길어진다(15.3턴 vs 10.8턴).
  조합을 안 가리는 고정 규칙의 한계이고 다음 실험 대상이다.

  방패병 몰빵은 ON·OFF 모두 0% 다. 편성으로 메울 수 없는 조합이 있다는
  경계를 보려고 넣은 자리라 의도대로다.

  구조 설명도 고쳤다. 클린 아키텍처 재배치(e4630d7) 때 README 를 빠뜨려
  core/adapters/api 로 남아 있었다.
