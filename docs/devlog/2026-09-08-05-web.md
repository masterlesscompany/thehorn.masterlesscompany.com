  투표 사용자가 서사 259줄 중 103줄에 "을(를)" 기계 토큰이, 35줄에 영문 id 가
  남아 있다고 지적했다. 받침을 보고 조사를 고르는 함수를 양쪽에 넣고(core/agents/

  끝나 조사를 고를 수 없던 소환 유닛 이름을 한글 서수로 바꿨다.

  평가 담당이 200시드 짝비교로 E1 의 방향을 뒤집은 원인을 특정했다. 후퇴 비용도
  승산 오보정도 아니었고, 20시드 관측으로 넣었던 "잡졸 먼저 치기" 와 "전사는
  전부 전열" 두 줄이었다. 보스는 3턴마다 수하를 부르므로 목표가 계속 갈아타
  보스 처치가 47판에서 8판이 됐고, 전열이 방패가 되는 전장에서 전원을 앞에
  세우면 잘 때리는 사람이 먼저 죽는다. 둘을 고치니 감독이 어떤 조합도 해치지
  않는다 — 균등 94% vs 74%(p<0.0001), 나머지 셋은 차이 없음.

  30판은 어떤 결론도 지지하지 못한다는 지적도 받아들였다. ON/OFF 가 같은 시드를
  쓰므로 짝비교(McNemar)를 표와 JSON 에 싣고 기본 시드를 200 으로 올렸다.

  E3 의 세 축은 계수가 같아 수학적으로 구별되지 않았다. 축마다 다른 항을 흔들게
  했다 — 위험은 자기 상처를, 희생은 동료의 죽음과 두고 온 가족을, 협동은 전반을.

  그 밖: E3 지표가 적의 행동 41%를 섞어 세던 것, 리플레이가 성별을 되돌리던 것,
  지혜 마스킹이 화면에 한 줄도 안 나오던 것, 모르는 런 id 가 이유 없이 "끊겼다"로
  끝나던 것, 모바일에서 인스펙터가 화면 밖으로 밀리던 것, 전멸한 후퇴가 후퇴로
  집계되던 것을 고쳤다.
