- **기획서를 v3 로 올렸다 — 세계관 확정 · 마법 배제 · 쓰러짐 3분기 · 뿔피리**
  통합시나리오와 v3 설계안을 상위 규범으로 두고 기획서를 다시 썼다. 두 원본
  문서도 저장소로 옮겨 기획서가 참조한다.

  v2 의 장 번호를 그대로 뒀다. 문서 곳곳이 §4.2·§8.3 처럼 서로를 참조하고
  있어 장을 새로 끼우면 참조가 전부 깨진다. 세계관은 §0 을 0.1~0.3 으로
  쪼개 넣었고, 나머지 신설 절은 6.0·6.8·7.1a·7.1b·8.4·8.5 처럼 기존 번호
  아래에 붙였다.

  주요 변경 열여덟 건은 13장 표에 있다. 그중 무거운 것 넷:

  마법을 전면 배제했다. 지능에서 "마법 위력" 을 지웠다. 힐러를 넣는 순간
  사망률 곡선과 자원 딜레마가 동시에 무너진다는 것이 근거다.

  HP 0 이 즉사가 아니게 됐다. 부상·끌려감·사망 3분기이고 사이클별 확률표가
  있다. 1~4 출동은 사망 0% 다 — 첫 상실이 죽음이 아니라 회수 여부라는
  선택으로 온다.

  뿔피리 3회를 넣었다. 유저의 유일한 전투 중 개입이다. 무한이면 조종하는
  게임이 되고 0 이면 관전이라 셋이다. 우선순위 방어선 2번에 올렸다 — 버튼
  하나로 투표 유저에게 30초 안에 전달되고 E7 의 재료가 된다.

  보스가 판을 넘어 학습한다. 학습 카드 4대 출처가 전부 유저의 자원 결정과
  연결된다. 보스 이름은 첫 끌려감 대원의 이름으로 생성된다.

  팀원용_스토리라인 을 지웠다. 어제 구두 설명으로 쓴 것인데 통합시나리오가
  같은 자리를 더 정확히 채운다. 팀원용_쉬운설명서 는 v2 기준이라 낡았다는
  표시만 달아 뒀다 — v3 개정은 별도 작업이다.

  14장에 팀 결정이 필요한 항목 열여섯을 남겼다. 첫 줄이 A단계 1판을 무엇으로
  할 것인가다 — 통합시나리오는 6회차, v3 설계안은 1·3번 + 5회차로 서로 다르다.
