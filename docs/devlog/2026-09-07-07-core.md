- **트레이스 스키마 v1 과 판단 층을 구현했다 — 마스킹 · 승산 · 순응 · 재계획**
  트레이스 kind 목록은 설계 8장의 계약이다. 지혜는 프롬프트 필드 마스킹 4단계로
  "볼 수 있는 것"을 늘린다(기획서 §4.2). 승산은 코드가 계산하고 행운을 읽지 않는다
  (include_luck=False). 순응 판정은 성격 가중치 기반 결정론적 확률이고 모델이
  뒤집을 수 없다(§5.1·§9) — 기획서 9장 시나리오(HP 32%·힐러 사망·딸 2세)가
  0.6~0.8 로 재현된다. 재계획 트리거는 이탈·승산 붕괴(계단식)·적응·환경(§8.3).
