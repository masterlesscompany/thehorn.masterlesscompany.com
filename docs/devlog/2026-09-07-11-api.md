- **FastAPI 앱을 붙였다 — 런 생성 · SSE 스트림 · 저장 · 리플레이 · 시크릿**
  런은 백그라운드 스레드에서 돌고 이벤트를 큐에 넣는다. 스트림은 중간에 붙어도
  처음부터 보내고, 끝나면 done 을 보낸다. 완료된 런은 JSONL 로 남아 새로고침해도
  같은 화면이 나온다. /replay 는 Replay 모델로 같은 판을 모델 호출 0 으로 다시
  돌린다(기획서 §11.3). 공유 시크릿은 secu-agent 방식 — 비어 있으면 로컬로 본다.
