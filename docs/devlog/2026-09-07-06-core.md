- **진영 대칭 전투 엔진을 구현했다 — 상태 · 판정 · 순서 · 행동 해석**
  보스전도 PvP 도 같은 코드다(기획서 §7.3). 명중·피해·속도는 내역(breakdown)을
  항상 붙여 돌려준다 — 인스펙터가 "명중 62% = 기본 60 + 민첩차 +6 - 무게 미달
  -10" 을 보여줘야 한다(§9). 행운은 굴림 보정에만 걸린다(§4.2). 근접은 전열이
  살아 있으면 후열을 못 노리고, 흐릿한 판단은 예외 대신 대상 변경 + 기록으로
  받는다. 스태미나 0 은 WAIT 만 — "무거운 갑옷 입으면 금방 지친다" 의 실체다.
