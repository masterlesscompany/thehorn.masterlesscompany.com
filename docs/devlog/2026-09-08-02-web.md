- **실험 러너 E1·E2·E3 와 실험 화면을 붙였다 — A단계 남은 두 항목 중 하나**
  기획서 §10.1 이 A단계 ● 로 표시한 E1(조합별 감독 ON/OFF)을 구현했다. 지표는
  트레이스 후처리만으로 나온다 — 러너를 고쳐야 지표가 나오면 실험이 코어를
  건드리게 되고 그것이 §3.1 이 막으려는 것이다.

  E1 실측(조합당 시드 30, Fake 모델):
    균등      감독 ON 93% / OFF 83%   생존 99% / 92%
    마법사 몰빵  감독 ON 63% / OFF 57%   생존 86% / 68%
    힐러 없음   감독 ON 60% / OFF 80%   생존 72% / 91%
    전사 몰빵   감독 ON 13% / OFF 33%   생존 71% / 76%

  두 조합에서 감독이 승률을 깎는다. 감독이 후퇴를 명령하기 때문이고, 후퇴한
  24판에서 사망자가 감독 없이 싸운 쪽과 같은 21명이었다 — 아무도 더 살리지
  못하면서 판만 버렸다. Fake 감독의 판단 품질 문제이지 기구의 고장은 아니다.
  QA 라운드 2에서 평가 페르소나에게 이 숫자를 그대로 들려 보낸다.

  E3 은 성향 축이 실제로 행동을 가르는 것을 보여준다 — 희생 수용도 -80 에서
  이탈 16.3회/판, +80 에서 2.4회/판.

  API 는 /experiments 목록과 /experiments/{name} 으로 일반화했다. 화면은 세
  실험을 한 페이지에 그린다(외부 차트 라이브러리 없이 SVG).

  기획서 조항 대조표를 docs/spec-trace.md 에 만들었다. A단계에 남은 것은 배포뿐이다.
