- **클래스 개편 설계를 적었다 — 마법사 삭제 · 방패병 신설 · 성직자를 음유시인으로**
  전투 역할이 흐릿했다. 전사가 방패도 들고 딜도 했고, 마법사는 궁수와 역할이
  겹쳤다. 막는 쪽·때리는 쪽·살리는 쪽으로 가른다. E1 이 조합의 좋고 나쁨을
  재는 실험이라, 조합이 선명해질수록 실험이 강해진다.

  방어/공격을 행동 금지로 만들지 않고 수치로 가르기로 했다. 기획서 §4.3
  "'장착 불가' 대신 페널티" 와 같은 원칙이다. 방패병의 방어 가치는 이미 있는
  전열 차단(resolve.py 의 reachable)에서 나오므로 엔진을 건드리지 않는다.

  음유시인의 응원은 bless 가 이미 "아군 전체 명중 상승" 이라 그대로 맞는다.
  치료는 heal 이다. can_heal 이 스킬에서 파생되므로 E1 "힐러 없음" 도 성립한다.

  세라핀이 갖고 있던 수읽기형 데모 슬롯은 새 방패병이 승계한다. 안 그러면
  기획서 §7.4 의 다섯 장면 매핑이 깨진다.
