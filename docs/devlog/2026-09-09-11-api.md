- **호출 예산을 계약 길이만큼 잡고, 예산 밖 호출도 세게 했다 — QA P0-F**
  MAX_CALLS=300 이 런당 하나의 하네스에 걸려 있어 18출동을 흉내 내면
  8회차부터 모든 판단이 조용히 Fake 로 떨어졌다. 게다가 예산이 바닥나면
  호출을 세지 않아 calls_used 가 0 을 찍었다 — "호출 300 이하" 검사가
  모델을 아예 안 쓴 판에서 가장 예쁘게 통과했다.

  예산은 전투 한 판 기준이다(기획서 §7.1). ModelFactory 가 계약 길이를
  받게 해 러너가 판 수를 넘기고 build_harness 가 그만큼 예산을 잡는다.
  타입이 강제하므로 새 진입점이 예산을 빠뜨릴 수 없다.

  예산 밖 호출도 세고, mission_end 가 판마다 fallbacks 를 싣는다.
  조용한 폴백이 트레이스에 남는다.

  18출동을 실제로 돌리는 회귀 테스트를 붙였다 — 판당 호출 5~61,
  폴백 전 구간 0. 나머지 16판의 콘텐츠는 사유를 적고 B단계로 미룬다.
