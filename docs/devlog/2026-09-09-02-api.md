- **뿔피리와 결과 5등급을 넣었다 — 유저의 유일한 전투 중 개입**
  기획서 v3 §8.2·§7.1b. 우선순위 방어선 2번이라 남은 것들보다 먼저 했다 —
  버튼 하나로 투표 유저에게 "내가 뭘 할 수 있는지" 가 30초에 전달되고, E7 의
  재료가 된다. A단계 데모에 유저의 전투 중 행동이 지금 하나도 없었다.

  둘을 함께 넣은 이유는 짝이기 때문이다. 뿔피리를 불면 「철수」 가 나와야 하고,
  「철수」 가 실패와 구분돼야 "벌점이 아니다" 가 표현된다. 포기 판단을 시스템이
  처벌하면 "싸울 가치가 있는가" 를 묻는 §8.3 이 죽는다.

  core 는 잔여 횟수도 누가 부는지도 모른다. 턴 시작에 "지금 울렸나" 만 묻는다 —
  장부는 호출자가 든다. HornFn 을 Protocol 이 아니라 Callable 로 둔 것은
  IntermissionFn 과 같은 이유다(구현이 둘, 형태가 단순).

  울리면 그 턴의 소환도 행동도 없다. 그 자리에서 전원이 빠져나온다.

  등급은 승패와 사상자를 함께 보고 접는다. 사망이 하나라도 있으면 무엇을
  이겼든 참사다. 부가 목표(시신·장비 회수)가 아직 없어 지금의 「완전 성공」은
  "이기고 아무도 안 다쳤다" 다 — 부가 목표가 생기면 첫 분기만 늘어난다.

  API 는 POST /runs/{id}/horn 이다. 3회를 다 쓰거나 판이 끝나면 409 다.

  검증: ruff, pytest 400, 프론트 22 + tsc.
