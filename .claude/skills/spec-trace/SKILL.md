# 기획서 조항 추적

기획서(`docs/기획/기획서_v2_2026-09-06.md`) §4~§11 의 각 조항이 어디에 구현되고 어떤 테스트가 지키는지를 `docs/spec-trace.md` 한 표로 유지한다.

## 절차
1. 표의 각 행: `조항 | 설계 문서 절 | 구현 파일 | 테스트 | 상태(● 구현 / ○ 부분 / – 타입만 / ✗ 없음)`.
2. 새 마일스톤이 끝나면 변경된 파일을 grep 해 대응 행을 갱신한다.
3. 상태가 `✗` 인 A단계(9/20) 조항이 있으면 그것이 다음 작업이다. B단계 조항의 `✗` 는 계획에 있는지 확인한다. C단계는 `–` 가 정상이다.
4. 코드 주석에 `기획서 §x.y` 인용이 없는 구현은 인용을 붙인다 — 다음 사람이 왜를 찾지 않게.
