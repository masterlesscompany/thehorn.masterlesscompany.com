# 에르덴 용병단

**캐릭터를 조종하는 게임이 아니라, 고용하는 게임.**
자율 캐릭터 멀티에이전트 자동대전 — 게임을 검증 환경(testbed)으로 쓴다.

> Wanted AI Championship 2026 출품작 · 기획서는 [`docs/기획/`](docs/기획/)

---

## 무엇이 다른가

에이전트 데모는 흔하다. **에이전트가 제멋대로 움직이는데 왜 그랬는지 전부 설명되는 것**은 흔하지 않다.

당신은 변경의 용병단 단주다. 단원 다섯 중 셋을 골라 폐광의 군주에게 보낸다. 그다음부터 손을 뗀다.
전장에서는 단장 AI 가 작전을 짜고, 단원 AI 가 매 턴 판단한다 — 때로는 방침을 어기고, 때로는 도망친다.

```
행동: 카일이 전장을 이탈했다
├ 입력된 상황: HP 33%, 아군 이탈 1, 부양가족 1
├ 이탈 압력: HP 0.335 + 아군 이탈 0.1 + 생애 0.2 = 0.635
├ 성향 보정: 위험 +0.09, 희생 +0.12, 협동 -0.04  → +0.17
├ 순응 판정: 이탈 확률 0.95, 주사위 0.13 → 이탈
└ 사유: "여기서 죽을 수는 없다. 두 살 딸이 집에 있다."
```

화면에서 그 행동을 클릭하면 이 기록이 열린다. 플레이어는 단원의 속마음을 못 보지만, 우리는 전부 안다.
**그래픽은 없다.** 대사와 흐름과 판정값뿐이다. 이건 못 만든 게 아니라 안 만든 것이다 — 이 프로젝트의
정체는 게임이 아니라 **에이전트 트레이스 뷰어**다.

## 세 장면

| 장면 | 무엇이 보이는가 |
|---|---|
| **이탈** | 두 살 딸이 있는 궁수가 방침을 버린다. 이탈 확률·성향 보정·주사위가 전부 남는다 |
| **포기** | 단장이 "어떻게 이기는가" 이전에 "싸울 가치가 있는가"를 판단하고 사람을 데리고 나온다 |
| **읽힘** | 보스가 같은 자의 반복 공격·마법 편중·반복된 치유·방어 일변도를 관측하고 대응한다 |

## 돌려보기

자격증명이 없어도 게임 전체가 돈다 — 기본 모델이 규칙 기반 Fake 다. 판단이 LLM 보다 단순할 뿐
규칙·로그·인스펙터는 동일하다.

```bash
# 백엔드
cd backend && uv sync --dev
uv run uvicorn apps.arena.adapter.inbound.api.v1.arena_router:create_app --factory --port 8000

# 화면 (다른 터미널)
cd frontend && npm ci
BACKEND_URL=http://localhost:8000 npm run dev     # http://localhost:3000
```

또는 한 번에:

```bash
docker compose up --build
```

## 구조

```
backend/
  apps/arena/            바운디드 컨텍스트 하나. 안쪽 → 바깥 3층이다
    domain/              최내층. 표준 라이브러리만 — 프레임워크도 콘텐츠도 모른다
      entities/            엔티티 · 값 객체 · 트레이스 이벤트 스키마
      ports/               경계 Protocol (안쪽이 소유, 바깥이 구현)
      constants/           밸런스 수치의 단일 출처
      services/rules/      주사위 · 신체 · 능력치 · 효율 스펙트럼 · 판정 — 순수 함수
      services/battle/     진영 대칭 전투 상태 머신
      services/judgment/   지혜 마스킹 · 승산 · 순응 판정 · 재계획 트리거
    app/use_cases/       유스케이스. domain 만 안다
      runner.py            미션 N개 + 인터미션. N 은 파라미터다
      agents/              단장 · 단원 · 보스 — 포트를 통해 모델을 부른다
      intermission/        육성 턴 · 생애 이벤트 · 성장 포인트
    adapter/             최외층
      inbound/api/         FastAPI — 얇은 HTTP 계층
      outbound/strategies/ 주사위 · fake · replay · 하네스
      outbound/repositories/ JSONL 런 기록
  core/                  BC 밖 전역 인프라 — 공유 시크릿
  content/               BC 밖 세계관 — 로스터 · 클래스 · 몬스터 · 환경 · 미션
  eval/                  BC 밖 실험 러너 E1·E2·E3
frontend/                Next.js — 진입 · 로스터 · 2패널 뷰어 · 결과 · 실험
```

**의존성은 항상 안쪽을 향한다.** `backend/tests/test_boundaries.py` 가 AST 로 강제하고,
기획서의 약속 세 가지도 같은 방식으로 굳혀 두었다:

| 기획서 조항 | 테스트 |
|---|---|
| 성별은 전투·능력치·판단에 영향 0 | `gender` 를 읽는 곳은 서사 표기와 리플레이 기록뿐 |
| 행운은 굴림에만, 판단에 미개입 | `luck` 을 읽는 파일은 `domain/services/rules/combat.py` 하나뿐 |
| MBTI 는 표기일 뿐 | 조립된 프롬프트에 MBTI 문자열이 없다 |
| 같은 시드는 같은 판 | 난수는 전부 `Dice` 포트를 통한다. CI 가 **다른 프로세스**에서도 확인한다 |

## 실험 — 말이 아니라 숫자로

```bash
cd backend && uv run python -m eval.run -e e1 -n 30
```

**E1 · 단장이 실제로 도움이 되는가** (조합당 시드 200, Fake 모델)

ON/OFF 가 같은 시드를 쓰므로 짝지어 비교한다 — 비율만 보면 30판에서 3판 차이가 잡음과 구별되지 않는다.

| 조합 | ON 승률 | OFF 승률 | ON만 이김 / OFF만 이김 | p | 판정 |
|---|---:|---:|---:|---:|---|
| 힐러 없음 | **84%** | 26% | 119 / 3 | <0.0001 | 유의하게 이득 |
| 균등 | **96%** | 80% | 38 / 5 | <0.0001 | 유의하게 이득 |
| 방패병 몰빵 | 0% | 0% | 0 / 0 | 1.00 | 아무도 못 이긴다 |
| 전사 몰빵 | 78% | 94% | 5 / 38 | <0.0001 | **유의하게 손해** |

단장은 **힐러가 없을 때 가장 크게 이득이다** — 승률이 26% 에서 84% 로 오른다. 치유가 없으면
편성과 집중 목표가 곧 생존이고, 그것이 단장이 하는 일이다.

**전사 몰빵에서는 단장이 오히려 손해다**(94% → 78%). 이걸 감추지 않는다. 편성 규칙이
"가장 잘 때리는 하나를 전열 뒤에 세운다"인데, 전원이 근접이면 앞에 남은 둘이 먼저 무너지고
판이 길어진다(평균 15.3턴 vs 10.8턴). 조합을 안 가리는 고정 규칙의 한계이고, 다음 실험 대상이다.

방패병 몰빵은 ON·OFF 모두 승률 0% 다. 전원 방어형이라 적을 죽일 화력이 없다 — 편성으로
메울 수 없는 조합이 있다는 뜻이고, 그 경계를 보려고 넣은 조합이다.

여기 오기까지 200시드 짝비교가 여러 결함을 잡아냈다 — 20시드 관측으로 넣었던 "잡졸 먼저 치기"와
"전사는 전부 전열"은 소표본에서 그럴듯했고 대표본이 뒤집었다. 과정은 [QA 기록](docs/qa/)에 있다.

**E3 · 성향이 실제로 행동을 가르는가** (수준당 시드 200, 다른 축은 0 고정)

| 축 | 수준 | 이탈 / 판 | 방어 비율 | 승률 |
|---|---:|---:|---:|---:|
| 위험 성향 | -80 / 0 / +80 | 14.2 / 7.0 / 3.3 | 21% / 12% / 6% | 69% / 92% / 98% |
| 희생 수용도 | -80 / 0 / +80 | 11.7 / 7.0 / 4.3 | 18% / 12% / 8% | 73% / 92% / 96% |
| 협동 성향 | -80 / 0 / +80 | 13.3 / 7.0 / 3.7 | 20% / 12% / 7% | 68% / 92% / 95% |

세 축이 서로 다른 항을 흔든다 — 위험은 자기 상처를, 희생은 동료의 죽음과 두고 온 가족을,
협동은 자리를 지키는 성향 전반을. 다양성이 말이 아니라 **검증된 판단 분기**라는 뜻이다.

## 검증

```bash
cd backend  && uv run ruff check . && uv run ruff format --check . && uv run pytest -q
cd frontend && npm test && npx tsc --noEmit
```

파이썬이 만든 `docs/trace-samples/one-run.jsonl` 을 프론트 테스트가 읽는다 — 양쪽이 같은 파일을
읽으므로 트레이스 계약이 갈라질 수 없다.
